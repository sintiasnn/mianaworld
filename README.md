# mianaworld

All about miana / coleus plant — a personal website built with vanilla HTML, CSS, and JavaScript.

## Features

- Responsive design with mobile-first approach
- Image lightbox gallery
- Scroll animations (Intersection Observer API)
- Active navigation highlight
- Back-to-top button

## Tech Stack

- **Build tool**: Vite
- **Frontend**: HTML, CSS (custom properties), JavaScript (ES Modules)
- **Typography**: Poppins + Nunito

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
